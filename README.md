# AudioVisualizer-HelperLibrary
library I made for my mp3 player app to help handle music related tasks                 

##### includes helper classes for my mp3 file management/streaming/downloading/tag editing app          
- Burner - handles cd burning                
- Downloader - handles downloading mp3 files using youtube explode             
- VisualHelper - handles visual related tasks (extracting color from cover,  bitmap/ipicture converting, color manipulations)            
- AudioHelper - handles sampling and fft of the files for the audio visualizer
